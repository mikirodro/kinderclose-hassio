# Imagen de KinderClose

`kinderclose.png` es el logo original descargado de https://app.kinderclose.com/images/kinderclose.png.

Los recursos instalables están en `custom_components/kinderclose/brand/`:

- `icon.png` y `icon@2x.png`: símbolo del logo original en formato cuadrado, 256 y 512 píxeles.
- `logo.png` y `logo@2x.png`: logo completo con proporción original, con alturas de 128 y 256 píxeles.

Las imágenes identifican el servicio KinderClose. Este proyecto es una integración no oficial; la marca y el logo pertenecen a sus respectivos titulares.
