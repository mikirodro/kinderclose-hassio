# Política de seguridad

## Versiones compatibles

Las correcciones de seguridad se preparan para la última versión publicada. Actualiza mediante el Marketplace de Home Assistant (o HACS en versiones anteriores a 2026.11) y reinicia Home Assistant para cargarla.

## Notificar una vulnerabilidad

Comunica los problemas de seguridad de forma privada mediante [Report a vulnerability en GitHub](https://github.com/mikirodro/kinderclose-hassio/security/advisories/new). Necesitarás una cuenta de GitHub. Evita abrir incidencias o pull requests públicos con detalles que permitan explotar el problema.

Describe el impacto, la versión afectada y pasos de reproducción con datos ficticios. No adjuntes contraseñas, tokens, cookies, HTML real de KinderClose, identificadores ni información de menores. El mantenedor revisará el informe y coordinará contigo la solución y su posible publicación; no se garantiza un plazo concreto de respuesta.

Si has expuesto una credencial, revócala o cámbiala desde el servicio correspondiente.
